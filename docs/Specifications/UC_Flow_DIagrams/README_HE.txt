TRACE — מסמך Use Cases מפורט עם דיאגרמה לכל מקרה שימוש

תכולה:
1. TRACE_MVP_Detailed_Use_Cases_With_Diagrams_HE.docx — המסמך הראשי לעריכה.
2. TRACE_MVP_Detailed_Use_Cases_With_Diagrams_HE.pdf — גרסת PDF לצפייה/שיתוף.
3. diagrams/ — קבצי PNG נפרדים לכל דיאגרמת Use Case.
4. trace_use_cases_extracted.json — מקור מובנה שנוצר מתוך מסמך האפיון הסופי, לשימוש טכני/מעקב.

הערה:
הדיאגרמות הן תרשימי זרימה תפעוליים לכל Use Case, ולא דיאגרמת Use Case כללית אחת.
