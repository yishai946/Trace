שדה חיפוש מקום במרכז ה-AppBar: מטיס את המפה לכתובת, יישוב, נחל או נקודת ציון.

- `.tc-search`: אייקון חיפוש ו-`input` (combobox) עם הכיתוב "חפש מקום, כתובת או נחל…" ותווית נסתרת "חיפוש מקום". כשיש טקסט, `.tc-search__clear` (×, עם `aria-label="נקה חיפוש"`) בקצה הסוף מנקה אותו.
- התוצאות נפתחות ברשימה מתחת לשדה. בחירה מטיסה את המפה למקום ומסמנת אותו.
- אותו שדה משמש לבחירת מקום בטופס (נקודת כינוס, מיקום אחרון ביצירת מסע), עם תווית גלויה.
- `.tc-kbd` שמור לקיצור מקלדת, כשיהיה. כרגע אין קיצור, ולא מציגים אותו.

הצרכן מספק: התוצאות מהגאוקודר, ומה קורה בבחירה.

לא לעשות: חיפוש מחפשים או פוליגונים בשדה הזה: הם ברשימות שלהם.
