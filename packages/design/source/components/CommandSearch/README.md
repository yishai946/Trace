שדה חיפוש ופקודות אחד לכל המערכת, במרכז ה-AppBar. נפתח גם ב-Ctrl K.

- `.tc-search`: אייקון חיפוש, `input` ו-`.tc-kbd` עם קיצור המקלדת. כשיש טקסט, `.tc-search__clear` (×, עם `aria-label="נקה חיפוש"`) בקצה הסוף מנקה אותו.
- מוצא מחפש לפי מספר או שם, פוליגון לפי שם, ופעולה ("שבץ 21 למדרון דרומי", "השהה מסע").

הצרכן מספק: תוצאות מקובצות (מחפשים, פוליגונים, פעולות), ופעולה שמתבצעת בבחירת תוצאה.
