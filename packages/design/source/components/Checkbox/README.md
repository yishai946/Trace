תיבת סימון, עיגול בחירה ומתג: בחירת נמענים, פוליגונים, הרשאות והעדפות.

- `.tc-check` היא התווית כולה (`<label>`), בגובה `control-h-sm` לפחות ובטלפון `touch-target`. בתוכה `.tc-check__box` בגודל `checkbox` עם סימן V בגודל `check-icon`; מסומנת: `.tc-check__box--on`, מילוי `accent`.
- `.tc-radio` לבחירה אחת מתוך כמה, `.tc-radio--on` לנבחרת.
- `.tc-switch` להפעלה וכיבוי שחלים מיד (למשל שיתוף מיקום), `.tc-switch--on` כשהוא דולק.
- מושבת: `aria-disabled="true"` ושקיפות `opacity-disabled`.
- הקלט עצמו הוא `<input type="checkbox">` או `radio` אמיתי; הקופסה מציירת אותו.

הצרכן מספק: התווית, המצב, ומה קורה בשינוי.

לא לעשות: מתג לבחירה שנשמרת רק בלחיצה על "שמור". תיבת סימון בלי תווית לחיצה.
