סרגל הלשוניות בתחתית המסך בטלפון: הניווט הראשי של Command בטלפון ושל Field.

- `.tc-tabbar` בגובה `tabbar-h`, עם `<nav>`. כל `.tc-tabbar__item` הוא קישור עם אייקון `icon-lg` ותווית `caption`. כל פריט ממלא את רוחבו, ומטרת המגע לפחות `touch-target`.
- המסך הנוכחי: `aria-current="page"`, בצבע `accent` ובמשקל 600.
- `.tc-tabbar__n` הוא מונה עגול בגודל `count-badge` על האייקון (הודעות שלא נקראו, דיווחים חדשים). `.tc-tabbar__n--danger` ל-SOS פעיל.
- Command בטלפון: לוח, מחפשים, דיווחים, הודעות, SOS. Field: מסע, דיווחים, הודעות, SOS, עוד. שאר המסכים (ציר זמן, בקרת מסע, פרטי מסע, פרופיל) נפתחים מהסרגל העליון או מ"עוד".

הצרכן מספק: הפריטים, הנוכחי ומונים.

לא לעשות: יותר מחמישה פריטים. אייקון בלי תווית.
