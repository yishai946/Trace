מספר הזיהוי הדו-ספרתי של מחפש. זה העוגן שמחבר בין המפה, הרשימה, ההתראה וה-Inspector.

- `.tc-callsign`: רגיל, על `chip`.
- `--sos`: מילוי `danger`. רק כשיש SOS פעיל.
- `--waiting`: מקווקו. מחפש שממתין לשיבוץ.
- `--offline`: מספר ב-`ink-muted`. אבד קשר או לא מקוון.

הצרכן מספק: מספר דו-ספרתי עם אפס מוביל (`07`), שזהה בכל מקום שבו המחפש מופיע.
