התראת SOS צפה בראש המפה, בין שני הפאנלים. ההתראה היחידה בממשק שקוטעת את מבט המנהל.

- `.tc-alert` עם `role="alert"`: תגית `.tc-alert__tag`, ואחריה טקסט עם מספר ושם מחפש מודגשים ופרטים ב-`.tc-alert__detail` (פוליגון, הודעה, שעה).
- שתי פעולות: "התקשר" (`.tc-btn--danger`) ו"פתח" (`.tc-btn--danger-ghost`) שבוחר את המחפש ופותח אותו ב-Inspector.
- כמה SOS פעילים בבת אחת: ההתראה מציגה את האחרון ומונה ("SOS · 2").

הצרכן מספק: מספר ושם מחפש, פוליגון, הודעה קצרה (אם צורפה) ושעה.

לא לעשות: להשתמש ברכיב הזה ליציאה מגבול, לסוללה או לכיסוי. כל אלה הם EventList.
