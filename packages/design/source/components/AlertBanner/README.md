התראה צפה בראש המפה, בין שני הפאנלים, ברוחב `alert-w`. ההתראות היחידות בממשק שקוטעות את מבט המנהל: SOS, דיווח "הנעדר אותר" ואזהרות בטיחות.

- `.tc-alert` עם `role="alert"`: תגית `.tc-alert__tag`, ואחריה טקסט עם CallsignChip ושם מחפש מודגשים ופרטים ב-`.tc-alert__detail`.
- כמה התראות נערמות מלמעלה למטה לפי חומרה: SOS, אחריו דיווח קריטי, ואחריו אזהרה.
- **SOS** (`.tc-alert`): רקע `danger-surface`. הטקסט: מספר ושם, פוליגון, שעת ההפעלה, ומיקום ("31.7431, 35.0127, עודכן 16:58" או "מיקום לא ידוע"). פעולה אחת: "פתח" (`.tc-btn--danger`) שפותח את מסך ה-SOS. כמה SOS פעילים: מוצג האחרון והתגית מונה ("SOS · 2"). כשמצב ה-SOS לא נטען: "לא ניתן לטעון את מצב ה-SOS, ייתכן ש-SOS פעיל. מנסה שוב." עם "נסה שוב".
- **דיווח קריטי** (`.tc-alert--report`): רקע `surface` ותגית `primary`. 'דיווח "הנעדר אותר" מ-07 אלון שגיא', השעה, ושורת הסבר "הדיווח אינו סוגר את המסע. רק המנהל מסיים אחרי אימות." פעולות: "פתח" (משני) ו"אמת וסיים מסע…" (`.tc-btn--primary`) שפותח את בקרת המסע.
- **אזהרה** (`.tc-alert--warn`): גבול `warning` ותגית מתאר ("אזהרה", או "אזהרה · 3" כשיש כמה). מחפש מחוץ לגבול, סוללה נמוכה, אובדן קשר, ספי Coverage. פעולות: "הבא" (רק כשיש יותר מאזהרה אחת, עובר לאזהרה הבאה), "פתח" (בוחר את המחפש) ו"סגור".
- בטלפון ההתראה היא שורה אחת מתחת לסרגל העליון (`meta`, נחתכת ב-…), בלי שורת ההסבר.

הצרכן מספק: מספר ושם מחפש, פוליגון, שעה, מיקום, ומספר ההתראות מאותו סוג.

לא לעשות: אירועים שאינם דחופים (דיווח רגיל, הצטרפות). אלה ב-EventList ובציר הזמן. כפתור "התקשר" בהתראה: ההתקשרות היא במסך ה-SOS וב-Inspector.
