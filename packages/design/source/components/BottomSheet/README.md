גיליון תחתון מעל המפה בטלפון: מחזיק את מה שבמחשב נמצא בפאנלים הצדדיים.

- `.tc-sheet` צמוד לתחתית מעל ה-TabBar, ברדיוס `radius-xl` בפינות העליונות ובצל `shadow-panel`. סגור, רואים רק את הידית ואת הלשוניות; פתוח (`.tc-sheet--open`) הוא בגובה `sheet-h`, ולכל היותר 45% מהמסך.
- `.tc-sheet__grab` הוא כפתור בגובה `touch-target` עם ידית `grab-w` על `grab-h`. הקשה עליו פותחת וסוגרת, עם `aria-expanded`.
- בתוכו SegmentedTabs ("התראות / מחפשים / דיווחים") שהלשוניות שלהן בגובה `touch-target`, ורשימה שנגללת בתוך הגיליון.
- תפריט הפרופיל ובחירות קצרות נפתחים גם הם כגיליון תחתון.

הצרכן מספק: הלשוניות, התוכן, ומצב פתוח או סגור.

לא לעשות: גיליון שמכסה את כל המפה. גלילה של הדף מאחורי הגיליון.
