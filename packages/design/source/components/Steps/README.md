סרגל צעדים לזרימה קצרה: כניסה (טלפון, קוד, שם) והצטרפות למסע.

- `.tc-steps` בראש המסך. כל `.tc-step` הוא עיגול `.tc-step__n` בגודל `step-marker` ותווית `meta`, ובין צעדים `.tc-step__sep`.
- הצעד הנוכחי: `.tc-step--on`, מילוי `accent`, ו-`aria-current="step"`. צעד שהושלם: `.tc-step--done` עם סימן V.
- שלושה צעדים לכל היותר.

הצרכן מספק: שמות הצעדים והצעד הנוכחי.

לא לעשות: צעדים לחיצים. סרגל צעדים בתוך דיאלוג.
