שדה טקסט עם תווית מעליו, לטפסים כמו הכניסה.

- `.tc-field` עם `.tc-field__label` ו-`.tc-input` בגובה `control-h`, גבול `border-field` ורקע `surface-sunken`.
- ערכים לטיניים (אימייל, סיסמה, קואורדינטות): `.tc-input--ltr`, כתובים LTR ומיושרים לקצה.
- שגיאה: `aria-invalid="true"` על השדות (גבול `warning`) והודעה אחת `.tc-field__error` עם `role="alert"` מתחתם. השגיאה לא חוסמת ניסיון נוסף.
- מושבת: שקיפות 45%.

הצרכן מספק: תווית, ערך, סוג השדה והודעת שגיאה.
