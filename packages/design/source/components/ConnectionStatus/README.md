נורית החיבור לשרת, תמיד בסרגל העליון לפני האווטאר: נקודה ומילה אחת.

- `.tc-status` עם `role="status"`, ובו `.tc-status__dot` והמילה.
- `.tc-status--up`: נקודת `success` שמהבהבת חלש, "זמין". רק כשיש רשת וגם השרת עונה (בדיקה כל 10 שניות).
- `.tc-status--down`: נקודת `danger` וטקסט `danger-ink`, "לא זמין". פעולות מבצעיות חדשות נחסמות; צפייה נשארת.
- בזמן הבדיקה הראשונה: בלי מחלקת מצב, נקודת `ink-muted` ו"בודק…".
- הסיבה ("אין אינטרנט" או "אין חיבור לשרת") והשפעתה ב-`title` וב-`aria-label`, לא בסרגל.
- `prefers-reduced-motion`: בלי הבהוב.

הצרכן מספק: מצב החיבור (רשת וזמינות השרת) והסיבה כשאין חיבור.

לא לעשות: הודעת טקסט ארוכה בסרגל במקום הנורית.
