שפת הסמלים על המפה, כמחלקות SVG שמקבלות את צבעיהן מהטוקנים ומתחלפות עם הערכה.

- פוליגונים: `.tc-poly--active` (מילוי ו-`accent`), `.tc-poly--done` (`ink-muted`), `.tc-poly--open` (מקווקו, לא משובץ). לכל פוליגון תגית `.tc-tag` עם אות ואחוז.
- מסלול מחפש: `.tc-route`, ורק בתוך הפוליגון שהמחפש משובץ אליו.
- מחפש: `.tc-sym-unit`, עיגול ברדיוס 5 עם `map-halo` ומספר ב-`.tc-sym-label` לצדו. וריאציות `--warn`, `--sos` (עם `.tc-sym-ring`) ו-`--offline`.
- LKP נוכחי: כוונת `.tc-sym-lkp` עם תווית שעה `.tc-sym-lkp-flag`. LKP קודם: `.tc-sym-lkp-old`.
- תצפית: מעוין `.tc-sym-sighting`. כינוס: `.tc-sym-rally` עם דגל. דיווח: ריבוע `.tc-sym-report`. מפגע: משולש `.tc-sym-hazard`.
- טקסט מפה: `.tc-map-text`, ונחלים `--water`.

הצרכן מספק: גאומטריה בקואורדינטות המפה. גודל הסמלים קבוע ואינו משתנה עם הזום.
