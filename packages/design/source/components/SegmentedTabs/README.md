מעבר בין תצוגות באותו פאנל, למשל "מחפשים / אירועים / דיווחים".

- `.tc-seg` עם `role="tablist"`, ובתוכו `.tc-seg__tab` עם `role="tab"` ו-`aria-selected`.
- שתיים עד ארבע לשוניות. המונה צמוד לתווית ("אירועים 5") ולא בתגית נפרדת.

הצרכן מספק: תוויות, מונים, והלשונית הנבחרת.

ניווט בין מסכים: קישורים עם `aria-current="true"` על הנוכחי, בלי `role="tab"` (ובלי `tablist` ללא `tabpanel`).

לא לעשות: ניווט בין מסכים בלשוניות אמיתיות. לשם כך יש בורר המסע וחיפוש הפקודות.
