מעבר בין תצוגות באותו פאנל או גיליון, למשל "התראות / מחפשים / דיווחים" בגיליון התחתון, או סינון "הכל / פעיל / מושהה / הסתיים".

- `.tc-seg` עם `role="tablist"`, ובתוכו `.tc-seg__tab` עם `role="tab"` ו-`aria-selected`.
- שתיים עד ארבע לשוניות. המונה צמוד לתווית ("אירועים 5") ולא בתגית נפרדת.
- בטלפון כל לשונית בגובה `touch-target`.
- מתג תצוגה של שני אייקונים (רשימה / מפה ב-Field) הוא אותו רכיב ברוחב `view-toggle-w`, עם `aria-label` לכל לשונית.
- בתוך חלונית (בורר סגנון מפה) אותה מסילה משמשת לבחירה אחת מתוך כמה.

הצרכן מספק: תוויות, מונים, והלשונית הנבחרת.

ניווט בין מסכים: Nav במחשב ו-TabBar בטלפון, לא לשוניות.

לא לעשות: ניווט בין מסכים בלשוניות אמיתיות.
