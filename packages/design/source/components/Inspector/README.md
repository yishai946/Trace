פאנל פרטים לפריט שנבחר: מחפש, פוליגון, דיווח או תצפית. צף בצד הסוף ברוחב `panel-end-w`.

- `.tc-panel`, שמחולק ל-`.tc-panel__section`:
  1. ראש: `.tc-inspector__head`, ובו CallsignChip או אות פוליגון, שם, שורת משנה ו"סגור".
  2. עובדות: `.tc-dl` בשתי עמודות. ערך רחב (מיקום, תיאור) מקבל `.tc-dl__wide`.
  3. פעולות: `.tc-actions` עם עד שלוש פעולות. הראשונה היא `primary`.
  4. פעילות: `.tc-activity` עם שעה ותיאור, מהחדש לישן.
- כשלא נבחר דבר, ה-Inspector מציג EventList.

הצרכן מספק: הישות שנבחרה, העובדות שלה, הפעולות הרלוונטיות לסוג שלה, והיסטוריה מתוך ציר הזמן.
