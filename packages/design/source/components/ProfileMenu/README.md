האווטאר בקצה הסרגל העליון. לחיצה פותחת פאנל עם פרטי המשתמש, ערכת הצבעים ויציאה.

- `.tc-avatar`: ראשי התיבות של השם (עד שתי אותיות) בגובה `control-h`, עם `aria-label` שמכיל שם ותפקיד.
- הפאנל: `.tc-panel.tc-profile` ברוחב `panel-end-w`, נפתח מתחת לאווטאר, בשלושה מקטעים:
  1. פרטים: `.tc-profile__who` עם אווטאר, שם (`.tc-profile__name`), תפקיד (`.tc-profile__meta`) ואימייל ב-LTR (`.tc-profile__email`).
  2. "ערכת צבעים": `.tc-select` עם "יום" (שמש), "לילה" (ירח) ו"לפי המכשיר" (מסך). ברירת המחדל היא לפי המכשיר.
  3. יציאה: `.tc-btn--danger-outline.tc-btn--block` עם אייקון יציאה.
- יציאה דורשת חיבור לשרת: בלי חיבור הכפתור מושבת עם הסבר, וכישלון מוצג בפאנל ("היציאה נכשלה. נסו שוב.").

הצרכן מספק: שם, תפקיד, אימייל, ההעדפה הנוכחית של ערכת הצבעים ופעולת יציאה.
