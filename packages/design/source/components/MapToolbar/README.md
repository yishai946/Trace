סרגל כלי עריכה ותצוגה למפה. צף במרכז התחתון של המפה.

- `.tc-toolbar` עם `role="toolbar"`. כלים הם `.tc-btn--icon`, והכלי הפעיל מסומן ב-`aria-pressed="true"`.
- `.tc-toolbar__sep` מפריד בין כלי עריכה (בחירה, פוליגון, מדידה, תצפית, LKP) לבין כלי תצוגה (שכבות, מפת בסיס).
- כלי תצוגה מקבלים תווית טקסט. כלי עריכה הם אייקון בלבד, עם `aria-label`.

הצרכן מספק: רשימת הכלים, הכלי הפעיל, ושם מפת הבסיס הנוכחית.
