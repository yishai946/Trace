סרגל כלי עריכה ותצוגה למפה. צף במרכז התחתון של המפה.

- `.tc-toolbar` עם `role="toolbar"`. כלים הם `.tc-btn--icon`, והכלי הפעיל מסומן ב-`aria-pressed="true"`. לכל כלי `aria-label` ותיאור צף מעליו.
- כלי עריכה: בחירה, ציור פוליגון, הוסף תצפית. ציור מושבת כשהמסע לא פעיל, ותצפית כשאין הרשאה.
- `.tc-toolbar__sep` מפריד בינם לבין שכבות התבליט, שכל אחת מתג נפרד: הצללת תבליט, קווי גובה, תלת-ממד.
- סגנון המפה (צבעונית, שחור־לבן, לוויין) לא נמצא בסרגל: הוא בבקר השכבות (MapControls).
- בטלפון הסרגל עומד אנכית בצד, והמפריד אופקי.

הצרכן מספק: הכלי הפעיל, אילו כלים מושבתים, ואילו שכבות תבליט דולקות.
