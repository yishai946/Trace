שורת מחפש ברשימה: מספר, שם, שורת מצב וסוללה.

- `.tc-unit` עם `.tc-callsign`, אחריו `.tc-unit__body` (שם ו-`.tc-unit__status`), ובסוף `.tc-unit__meta` לסוללה.
- מצב: `.tc-unit__status--warn` למחוץ לגבול ולא מקוון, `--danger` ל-SOS. סוללה נמוכה: `.tc-unit__meta--warn`.
- השורה כולה: `.tc-unit--sos` (רקע `danger-tint` עם גבול פנימי), `--selected` לפריט שמוצג ב-Inspector, `--offline` לשם מעומעם.
- בשורת המצב: מצב במילה אחת, ואחריו בעמודה נפרדת `.tc-unit__sub` הזמן היחסי מהעדכון האחרון או פרט החריגה ("80 מ׳"). בלי נקודה אמצעית.

הצרכן מספק: מספר, שם, מצב, זמן עדכון, סוללה באחוזים. לחיצה על השורה בוחרת את המחפש וממרכזת אותו במפה.

לא לעשות: להחליף את המילה בצבע לבד. תמיד "SOS" או "מחוץ לגבול" בטקסט.
