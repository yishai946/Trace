כותרת קבוצה ברשימת המחפשים: פוליגון, כמה מחפשים בו, ומד כיסוי.

- `.tc-group` עם `.tc-group__title`, מונה מחפשים, `.tc-meter` ובסוף אחוז.
- פוליגון שהושלם: `.tc-meter__fill--done` והמילה "הושלם" לפני האחוז.
- קבוצת "ממתינים לשיבוץ" נמצאת תמיד אחרונה, עם קישור "שבץ" במקום מד.

הצרכן מספק: אות ושם פוליגון, מונה, אחוז כיסוי (מחושב אוטומטית, אף פעם לא ידני), ומצב הפוליגון.
