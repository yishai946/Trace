תגית מצב קצרה על שורה או כרטיס: מצב דיווח, דחיפות הודעה, מצב הרשאה, "חדש".

- `.tc-badge` בגובה `badge-h`, רקע `chip`, טקסט `caption` במשקל 600. מילה אחת או שתיים.
- גוונים לפי משמעות: `--ok` (מאושר, מחובר), `--warn` (ממתין, חלש), `--accent` (חדש, חשוב), `--danger` (נדחה, SOS) על `danger-tint`.
- מלאים, רק למה שחייב לבלוט: `--solid` (מילוי `primary`) לדחיפות קריטית ולתגית "הנעדר אותר", `--solid-danger` ל-SOS.
- `--outline-warn` לתגית "אזהרה" בהתראה צפה.
- `.tc-dot` בגודל `dot` בתוך התגית כשהיא מתארת מצב חי ("מקוון").

הצרכן מספק: המילה והגוון.

לא לעשות: תגית בצבע בלבד, בלי מילה. יותר מתגית אחת בשורה.
