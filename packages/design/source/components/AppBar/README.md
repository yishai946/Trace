הסרגל העליון הצף, במרווח `space-6` מקצות המסך ובגובה `header-h`.

- סדר קבוע מימין לשמאל: מותג, מפריד, בורר מסע (`.tc-appbar__mission` עם נקודת מצב ושם הנעדר בלבד, בלי מספר המסע), זמן מסע וקוד הצטרפות (`.tc-appbar__meta`), חיפוש ופקודות באמצע, פעולות מסע (`.tc-appbar__actions`), נורית החיבור (ConnectionStatus) ואווטאר הפרופיל (ProfileMenu).
- הפעולה הראשית היחידה: "הנעדר אותר…". "השהה" ו"הפסק מסע…" הן משניות.
- Command Offline: נורית החיבור עוברת ל"לא זמין" באדום, ופעולות המסע מושבתות.
- מסכים בלי מסע פתוח (רשימת מסעות): מותג, ובסוף רק נורית החיבור והאווטאר. שם המשתמש והיציאה בתפריט הפרופיל.
- חלון צר: מותג, נורית ואווטאר לא מתכווצים; שם הנעדר והחיפוש מתכווצים, וקוד ההצטרפות מוסתר מתחת ל-900px.

הצרכן מספק: מסע נוכחי, מצב, זמן מתחילת המסע, קוד הצטרפות, מצב החיבור ומשתמש.
