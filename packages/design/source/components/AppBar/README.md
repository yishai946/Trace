הסרגל העליון הצף, במרווח `space-6` מקצות המסך ובגובה `header-h`.

- סדר קבוע מימין לשמאל: מותג, מפריד, בורר מסע (`.tc-appbar__mission` עם נקודת מצב), זמן מסע וקוד הצטרפות (`.tc-appbar__meta`), חיפוש ופקודות באמצע, פעולות מסע (`.tc-appbar__actions`) ואווטאר.
- הפעולה הראשית היחידה: "הנעדר אותר…". "השהה" ו"הפסק מסע…" הן משניות.
- Command Offline: נקודת המצב מתחלפת ל-`warning`, ליד הזמן מופיע "לא חי", ופעולות המסע מושבתות.

הצרכן מספק: מסע נוכחי, מצב, זמן מתחילת המסע, קוד הצטרפות ומשתמש.
