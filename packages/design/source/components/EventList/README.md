רשימת אירועים פתוחים שאינם SOS: יציאה מגבול, סוללה, אובדן GPS, ספי כיסוי והצעת LKP.

- `.tc-events`. כל `.tc-event` בנוי מאייקון קו (`.tc-event__i--warn`, `--accent`, `--ink`, `--danger`), טקסט שמתחיל במספר המחפש או באות הפוליגון, ושעה או קישור פעולה.
- `--warn` לחריגות של מחפש, `--accent` לכיסוי, `--ink` להחלטה שממתינה למנהל. לכל אייקון צורה משלו, והמילה בטקסט היא שנושאת את המשמעות.
- אין נקודת צבע באירועים. נקודת סטטוס שמורה לשם המסע.
- מוצגת ב-Inspector כשלא נבחר דבר, ובלשונית "אירועים".

הצרכן מספק: אירועים ממוינים מהחדש לישן, ופעולה לכל אירוע שדורש החלטה ("בדוק", "סמן הושלם").
